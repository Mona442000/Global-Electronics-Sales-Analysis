Global Electronics Retailer – Sales Performance Dashboard

Project Overview

An end-to-end sales analysis project focused on exploring business performance, identifying trends, and generating actionable business insights using Excel, SQL, and Power BI.

Tools & Technologies

* Microsoft Excel
* SQL
* Power BI
* DAX

Project Workflow

1. Data Cleaning: Cleaned and prepared the dataset using Excel and SQL.
2. SQL Analysis: Conducted data analysis to answer business questions and identify meaningful insights.
3. Dashboard Development: Built an interactive Power BI dashboard using DAX measures to monitor sales performance and key KPIs.

Key Analysis Areas

* Revenue and sales performance
* Sales trends over time
* Product category performance
* Customer distribution
* Brand performance

Dashboard

The Power BI dashboard provides an interactive overview of sales performance and highlights key business insights to support data-driven decision-making.
